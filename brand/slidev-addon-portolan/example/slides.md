# Portolan

A cloud-native geospatial data catalog standard.

---

## The type registers

Hanken Grotesk sets prose and headlines. JetBrains Mono sets the machine
register: `portolan check`, file paths, and data.

| Format | Role |
|---|---|
| GeoParquet | Tabular data |
| COG | Raster data |
| PMTiles | Tiles |

> Rules carry the structure. No cards, and no shadows.
