# Portolan

**Publish geospatial data as plain files in your own storage, connected into a searchable network.**

Portolan publishes geospatial data as plain files in your own storage, with no servers, databases, or accounts. Cloud-optimized formats and structured metadata let people and agents work with and build on the data directly, while the registry links every catalog into a searchable network of open data.

- [portolan-sdi.org](https://www.portolan-sdi.org/) for the full overview, architecture, and getting started.
- [Repositories](https://github.com/orgs/portolan-sdi/repositories) for the spec, the CLI, the validator, the registry, and the browser.
- The [Google Group](https://groups.google.com/g/portolan) and the [Portolan channel](https://cloudnativegeo.slack.com/archives/C0A1JBH9529) in the Cloud-Native Geo Slack for questions and discussion.
