# portolan-ops

Operations and coordination for **Portolan** — the home for work that isn't a library and doesn't (yet) have its own repo.

This repo isn't code — it's a **coordination board**. If a task needs tracking but there's no obvious repo for it, it goes here.

## What lives here

- **Infrastructure** — buckets, hosting, the shared [Portolan mirrors org on Source Coop](https://github.com/portolan-sdi/portolan-ops/issues/1), CDN, DNS, accounts
- **Tooling & coordination** — cross-repo efforts, external integrations (e.g. tracking the Carto browser release)
- **Promotion & communications** — blog posts, announcements, social, talks
- **Tutorials & docs** — how-to content and walkthroughs that don't belong to a single tool
- **Website** — content and updates for the Portolan site
- **Events** — conferences, meetups, community calls
- **Anything without a repo yet** — if it grows up, it can graduate into its own repo

## Get involved

- 💡 **Ideas welcome from anyone** — [open an issue](https://github.com/portolan-sdi/portolan-ops/issues/new).
- 🙋 **Claim an issue** — comment to pick something up.
